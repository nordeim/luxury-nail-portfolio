## 7. Decisions & Open Questions

1. **R6-01 is content parity, not feature invention** — the reference now carries prices and add-ons; the clone's superset mandate tracks the live reference, so the catalog grows to match. The booking contract is deliberately untouched: the reference's booking select still offers exactly the six services without prices, so add-ons stay out of `knownServices` (unit-pinned) — an add-on purchase path would be speculative scope the reference doesn't ship.
2. **AA wins over blind color parity; geometry wins over approximation.** The reference's static gold (2.97:1) is echoed by the AA-passing `--gold-ink` (5.29:1) rather than copied; the rose band accents ARE copied (they pass on both grounds). The R1-era "gold is hover/border only" rule is amended with the precise `--gold-ink` exception and its math, and the session-1 contrast decision is finally formalized as a ledger row (R6-07) rather than remaining oral history.
3. **Typography normalization ripples intentionally** — the eyebrow utility retune is a one-source fix; the capture series gains new baseline heights (30–32) and the R1–R5 "zero layout shift" record ends honestly. Historical evidence docs (sessions, prior plans) are left untouched per the evidence doctrine.
4. **Sub-perceptual ink deltas are recorded, not rippled** (§5 ink census) — changing core ink tokens for a ≤10-unit RGB delta would touch every surface in both themes with no visible parity gain; revisiting requires a full re-measurement round.
5. **CI workflow is authored but its run is not observable from this environment** (R6-05 confidence: Reasoned) — the next push to `main` triggers it; if the runner matrix needs adjustments (Playwright deps, caching), that is the next round's first check.
6. **Single-commit push** — one atomic commit (R6 plan + code fixes + tests + captures + doc/status alignment) to `main`, per the operator's standing instruction.
