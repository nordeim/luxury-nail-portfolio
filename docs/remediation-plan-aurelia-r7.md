Filter state is intentionally **not** persisted or URL-synced — the reference keeps it in-memory component state; matching that (and avoiding speculative scope) is the smaller, parity-faithful path.
2. **R7-04 rebuild keeps the clone's supersets where they are verified data** — the studio address/hours line (from the reference's own `/booking` info cards) stays in the studio section (ledger row added); the AA doctrine holds on the new surfaces (reference's gold eyebrows/stats-labels render in the clone's muted-foreground; the band reuses the AA-passing rose tokens measured in R6).
3. **The founder portrait is generated, not copied** — one new independently-generated portrait asset (IP boundary 6). If a future round replaces it, the alt text and aspect ratio (3:4) are the only contract.
4. **The quote glyphs change is deliberate micro-parity** — straight `"` matches the reference's literal blockquote text at 48px where the glyph difference is visible; the R6 accent-span pin is unaffected.
5. **Capture heights shift again** — the filter row (+~48px chip row on `/gallery`) and the About rebuild change the layout baselines; the R6 heights remain the record for the R6 tree, this round's captures are the new baseline.
6. **Single-commit push** — one atomic commit (R7 plan + code fixes + tests + captures + doc/status alignment) to `main`, per the operator's standing instruction.
